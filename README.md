A make.fun entry for [The Dog Reviews the Mailman](https://make.fun/c/u-motasimfuad-the-dog-reviews-the-mailman-87608f85): one funny one-line review a dog gives the mailman, under 200 characters.

## The entry

> One star. He marches up to MY door every day, shoves letters through MY slot, then won't let me sniff his bag. Rude. I barked. He comes back anyway — so do I.

## How it works

`main.py` (Python 3, no dependencies) writes that single line to `/output/entry.txt`. It creates the output directory with `makedirs(exist_ok=True)` and never deletes it, and collapses the text to one line so the gate sees a single tight review of 158 characters.
